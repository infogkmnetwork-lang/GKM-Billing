# GKM Admin - Android APK

1. Create a new GitHub repo (private is fine) and upload everything in this folder
   (including the hidden .github folder).
2. Go to the Actions tab -> "Build Android APK" runs automatically (or click Run workflow).
3. After ~5 min open the finished run -> Artifacts -> GKM-Admin-APK -> download, unzip, install app-debug.apk on the phone.

To update the app: replace www/index.html and push. A new APK builds automatically.
